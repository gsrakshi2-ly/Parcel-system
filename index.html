HOW IT WORKS

Sense. Send. Understand.

Physical sensors collect information around a parcel. The Arduino sends those measurements to the browser over USB, where PAQSAFE presents them clearly.

PQ
01

Detect

HC-SR04 measures distance. The water sensor provides an analog reading.

02

Transmit

The Arduino UNO sends a JSON line through its USB serial connection.

03

Monitor

PAQSAFE displays the received values and evaluates the water threshold.

QUICK HELP

Frequently asked questions

Does PAQSAFE need an ESP32?

No. This version uses a USB serial connection from the Arduino UNO to Chrome or Edge. An ESP32 is not required for this connection method.

Why are Parcels #002 and #003 marked demo?

Only one Arduino and one sensor pair are currently configured. The other two cards are visual examples and have no physical sensor connection.

Why are readings blank?

The website has not received a valid Arduino reading yet. Check the USB cable, selected serial port, baud rate and Arduino sketch. Close Arduino IDE Serial Monitor before connecting the website.

Can I change the water threshold?

Yes. Change it in Settings. PAQSAFE calculates the displayed water status from the raw sensor value received from the Arduino.

ABOUT THE PROJECT

About PAQSAFE

A parcel monitoring concept focused on making sensor information easier to understand.

P

DETECT. MONITOR. PROTECT.

Making parcel monitoring more visible.

PAQSAFE is a prototype that combines basic electronic sensors, an Arduino UNO and a browser dashboard. The aim is to demonstrate how live measurements can be presented alongside parcel records.

CURRENT PROTOTYPE

What is included

  • Arduino UNO USB serial connection
  • HC-SR04 distance sensor
  • Analog water sensor
  • Parcel registry with one live device parcel
  • Session-only reading analytics

IMPORTANT LIMITATION

Prototype disclaimer

This is an educational prototype, not a certified shipping-security product. Sensor readings depend on placement, wiring, calibration and the environment. The distance sensor does not identify a parcel by itself.

CONNECTION CHECKLIST

Before connecting

  1. Plug Arduino UNO into your computer using USB.
  2. Upload the PAQSAFE Arduino sketch.
  3. Select Arduino UNO and the correct COM port in Arduino IDE when uploading.
  4. Close Serial Monitor and Serial Plotter.
  5. Open this website over HTTPS in Chrome or Edge.
  6. Click Connect Arduino and select the serial device.
i

GitHub Pages uses HTTPS. Web Serial is not available in every browser. The browser and Arduino IDE Serial Monitor cannot normally share the same port at once.

SENSOR CONFIGURATION

Water threshold

Raw analog readings range from 0 to 1023. PAQSAFE marks water as detected when the reading is at or above this value.

Current threshold: 500

Calibrate this using your own dry and wet sensor readings. This threshold affects the website's displayed status; it does not alter the Arduino sketch.
