About this prototype

PAQSAFE is a student-developed parcel monitoring prototype. It combines a browser dashboard with an Arduino UNO R3 and sensors for an educational demonstration.

The website is a monitoring interface, not a certified security or shipping system. Sensor accuracy depends on hardware placement, wiring, calibration and the environment.
